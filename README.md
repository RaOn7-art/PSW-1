PERTANYAAN LAPORAN:
1. Mengapa telepon bukan kuantitas number?
    karena nomor telepon secara konsep adalah sebuah teks (string) yang kebetulan hanya berisi karakter angka, bukan sebuah nilai matematika.

2. Apa beda label pilihan dan legend kelompok?
        Label pilihan berfungsi untuk mengidentifikasi nilai spesifik yang akan dipilih oleh pengguna.
        Legend kelompok berfungsi sebagai payung hukum atau judul besar yang membawahi beberapa opsi yang saling berhubungan.
    
3. Apa beda id dan name?
        id sebagai tanda pengenal unik berbentuk angka untuk membedakan satu data dengan data lainnya
        name menyimpan label atau nama teks dari entitas yang bersangkutan

4. Apa yang terjadi pada checkbox tidak dicentang?
        browser tidak akan mengirimkan nilai atau nama checkbox tersebut sama sekali ke server saat form dikirim
